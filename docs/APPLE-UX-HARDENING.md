# CitizenAI Apple UX Hardening

Approved direction: apply the Home-page iOS 26 native mockup language across all 28 product screens without changing product scope, readiness semantics, certified knowledge-pack behavior, or backend contracts.

## Scope

1. Native-style navigation and persistent top-level tabs.
2. Floating iOS control layer; content remains calm and card-led.
3. 44pt minimum hit targets and stronger accessibility labels/states.
4. Dynamic Type-friendly layouts and text scaling behavior.
5. Purposeful haptics and subtle motion.
6. Platform-aware iconography with iOS-native symbol intent and Android fallback.
7. Dark/contrast-ready semantic design tokens.
8. Consistent spacing, hierarchy, cards, progress, lists, and quick actions across all 28 screens.

## Guardrails

- Keep the same information architecture: Home / Learn / Progress / Profile.
- Keep the same flows and runtime contracts.
- Keep readiness wording/status thresholds unchanged.
- Keep UK pack certification and provenance behavior unchanged.
- Do not apply glass to content cards; use it only for navigation/control surfaces.
- Validate Welcome → setup → diagnostic → readiness → Today plan → learning → reload persistence.
